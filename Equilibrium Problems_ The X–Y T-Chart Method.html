AP Physics 1, Forces

Solving equilibrium problems, one axis at a time

Every equilibrium problem gets the same start: split the page into an x-column and a y-column, and write the zero-sum at the top of each.

x
y
ΣFx = 0
ΣFy = 0

In this class we use g = 10 m/s², so the weight of an object is Fg = mg. A 4.00 kg object weighs 40.0 N.

What equilibrium means

Newton’s first law: an object keeps its velocity (stays at rest, or keeps moving at the same speed in the same direction) unless a net force acts on it.

So if the velocity isn’t changing, a = 0 and the net force is zero: ΣFx = 0 and ΣFy = 0.

Static equilibrium

The object is at rest and stays at rest: v = 0.

Clue words: hangs, is suspended, at rest, held in place.

Examples: a hanging sign, a knot joining ropes, a book on a table.

Dynamic equilibrium

The object moves at constant velocity: same speed, straight line.

Clue words: constant velocity, constant speed, steady, terminal velocity.

Examples: a crate pulled at steady speed, a skydiver at terminal velocity.

The math for both is identical. Moving at constant velocity is not a reason for a net force.

The method

  1. Sketch the situation and list what you know. Convert mass to weight right away: Fg = mg.
  2. Draw a free-body diagram. One dot or box for the object, and an arrow for every force acting on it, tails on the object.
  3. Break every angled force into components. Draw the x-part and y-part as dashed arrows.
  4. Draw the T-chart. Label the columns x and y. Start them with ΣFx = 0 and ΣFy = 0.
  5. Write out each sum. Right and up are positive; left and down are negative. A force only goes in a column if it has a part along that axis.
  6. Swap each component for its trig form, such as F cos θ or F sin θ.
  7. Solve the column that has only one unknown. Box the answer.
  8. Carry that answer across to the other column and solve it. Box that answer too.
  9. Check that the answers make sense. Are they positive? Is a rope pulling at an angle stronger than the weight it holds up?

Breaking a force into components

When θ is measured from the horizontal:

Fx = F cos θ
Fy = F sin θ

If a problem measures θ from the vertical, the two swap. Always check which side of the triangle the angle touches: the side it touches gets cos.

    Example 2: dynamic equilibrium

    A 4.00 kg crate is pulled across a rough floor at constant velocity by a rope angled 30° above the horizontal. Friction on the crate is 18.0 N. Find the applied force FA and the normal force FN.

    x
    y

    ΣFx = 0

    FAx − Ff = 0

    FA cos θ − Ff = 0

    Only one unknown here. Solve this column first.

    FA = Ffcos θ = 18.0cos 30°

    FA = 20.8 N

    ΣFy = 0

    FN + FAy − Fg = 0

    FN + FA sin θ − Fg = 0

    FN = Fg − FA sin θ

    FN = 40.0 − 20.8 sin 30°FA carried from the x-column

    FN = 29.6 N

      Common mistakes

      • Assuming FN = Fg every time. That’s only true when nothing else pushes or pulls vertically. A rope pulling up makes FN smaller; a push angled down makes it bigger.
      • Dropping the minus sign. Any arrow pointing left or down gets a minus sign when you write the sum.
      • Putting a whole angled force in one column. An angled force never goes in a column by itself. Only its components do.
      • Mixing up sin and cos. Look at where the angle is measured. The side of the triangle the angle touches gets cos.
      • Calculator in radian mode. Quick test: sin 30° should give 0.5.
      • Rounding too early. Keep the full number in your calculator when you carry it across. Round only the final boxed answers to three significant figures.

      A child pulls an 8.00 kg sled across the snow at constant velocity. The rope is 20° above the horizontal, and the child pulls with 30.0 N. Find the friction force Ff and the normal force FN.

      y

      y

      Practice 3

      A student pushes a 5.00 kg box across the floor at constant velocity. The push is directed 30° below the horizontal, and friction on the box is 26.0 N. Find the push FA and the normal force FN.

      Free-body diagram
      x
      y

      ΣFx = 0

      ΣFy = 0

      Dynamic equilibrium (constant velocity). Fg = 50.0 N. The push points down, so FAy gets a minus sign, and FN ends up bigger than the weight because the push presses the box into the floor.

      x
      y

      ΣFx = 0

      FAx − Ff = 0

      FA cos θ − Ff = 0

      FA = 26.0cos 30°

      FA = 30.0 N
